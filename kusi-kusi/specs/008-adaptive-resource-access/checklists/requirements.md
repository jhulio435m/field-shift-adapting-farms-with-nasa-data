# Checklist

- [x] Escenarios priorizados y comprobables.
- [x] Tenant, permiso global, ACL, revocación y fallo cerrado explícitos.
- [x] Diferencia entre conjunto analítico y registro individual delimitada.
- [x] Sin dependencias de proveedor necesarias para aceptación local.
- [x] Sin autorizaciones implícitas para despliegue o envíos.
